# DeAddict Production V1 Scope

Last updated: 2026-07-29

## Product definition

DeAddict is a private multi-habit recovery companion for adults who want structured self-management support across one or more compulsive behaviors.

Core promise:

> Understand your patterns, manage urges, and reclaim control without shame.

## Included in V1

### Accounts and privacy

- Guest/local-only mode
- Email OTP and Google sign-in
- Optional cloud synchronization
- Guest-to-account migration
- Account switching
- Export
- Delete local data
- Delete account
- Biometric lock
- Screenshot/recent-preview protection
- Neutral notifications
- Analytics off by default

### Recovery Tracks

- Permanent user-specific track IDs
- One active primary track
- Multiple supporting tracks
- Active, paused, maintenance, and archived states
- Historical journeys
- Restart as a new journey
- Independent goals, progress, events, Rescue, and insights

### Goals

- Quit completely
- Reduce quantity
- Daily and weekly limits
- Time limit
- Spending limit
- Delay first use
- No-use period
- Awareness only
- Structured custom goal
- Versioned goal history

### Daily loop

- Unified multi-track daily check-in
- Shared mood, stress, energy, and sleep context
- Goal-aware per-track outcomes
- One-off event tracking
- Offline-first saving
- Non-punitive slip recovery

### Tools

- Rescue
- Focus sessions
- Motivation reminder
- Trigger plan
- Replacement-action list
- Delay or breathing timer

### Progress and insights

- Goal-aware progress
- Confirmed aligned days
- Current and best streaks where appropriate
- Quantity, time, and spending comparisons
- Urges managed
- Rescue effectiveness
- Estimated time and money reclaimed
- Milestones
- Explainable track and cross-track insights

### Rook

- Direct, Brutal Banter, and Quiet
- Direct as default
- Explicit opt-in for Brutal Banter
- Deterministic reviewed templates
- Safety override
- Helpful, Too Far, Repetitive, and Not Relevant feedback
- Message repetition controls

### Commercial

- Free core recovery and Rescue
- Verified DeAddict Plus subscription
- Server-side entitlement verification
- Restore purchases
- Regional pricing support

## Explicitly deferred

- Public community
- Public profiles
- Leaderboards
- Social feed
- AI therapist
- Unrestricted generated Rook conversation
- Wearables
- iOS application
- Web companion
- Clinic dashboards
- Employer dashboards
- Live coaching
- Real-time chat
- Complex avatar economy

## Product boundaries

- Self-management support, not medical treatment
- No diagnosis
- No detox or taper instructions
- No guaranteed outcomes
- No sale of sensitive recovery data
- No targeted advertising based on recovery data
- No universal score combining different addictions
- A lapse in one track never changes another track

## V1 release-critical journeys

1. Install and continue privately.
2. Create a primary Recovery Track and valid goal.
3. Add an optional supporting track.
4. Complete a unified daily check-in.
5. Record an urge, limit exceeded, or slip.
6. Complete Rescue offline.
7. View real progress and next action.
8. Sign in and restore data without duplication.
9. Purchase and restore a verified subscription.
10. Delete the account and all associated data.

## Scope-change rule

Any proposed V1 feature must identify:

1. The customer problem it solves.
2. The metric it should improve.
3. The existing work it delays or replaces.
4. Its safety, legal, privacy, and data impact.
5. Whether it can ship after V1.
