# DeAddict Production Identity

## Locked values

- App name: DeAddict
- Developer name: MiCirql
- Support email: support@micirql.com
- Public website: https://deaddict.micirql.com
- Android application ID: com.deaddict.app

## Release usage

Use these values consistently across:

- Google Play Console developer profile and store listing
- Android application configuration
- Privacy policy and terms pages
- In-app support and legal screens
- Supabase authentication redirect URLs
- OAuth consent screens and provider configuration
- Transactional email templates
- Release notes and support documentation

## Identity constraints

The Android application ID `com.deaddict.app` is the permanent Google Play identity. Do not change it after the first production release.

The website should be configured with HTTPS and should publish, at minimum:

- Privacy policy
- Terms of service
- Support/contact page
- Account deletion instructions
- Data safety and retention information

Domain names are case-insensitive, but all product links should use the canonical lowercase URL `https://deaddict.micirql.com`.
